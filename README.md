# E‑Commerce Project

## Overview
This project demonstrates end‑to‑end data analysis and visualization using *Power BI* on an e‑commerce dataset. 
It covers importing, cleaning, and modeling data, building dashboards, and delivering insights to support business decisions.

## Dataset
The project uses three tables:
- *Orders*: Order details including product category, country, sales channel, and value.  
- *Customers*: Customer IDs and names linked to orders.  
- *Sales Targets*: Sales manager targets, team assignments, and completion ratios.  

## Objectives
- Import and clean data, fix miscategorized sales channels.  
- Build relationships using **Power Query** and **DAX**.  
- Evaluate sales performance and completion ratios.  
- Identify managers meeting or missing targets across time frames.  
- Create dashboards for KPIs, country‑wise sales, forecasts, and category analysis.  
- Add interactive features: Q&A, drill‑through reports, and mobile‑optimized views.  
- Deliver a polished *PBIX file* with themes, bookmarks, and presentation slides.  

## Skills Demonstrated
- Data cleaning and transformation  
- DAX modeling and calculations  
- Dashboard design and visualization  
- Interactive reporting (Q&A, drill‑through)  
- Mobile‑friendly report design  
- Storytelling with data for stakeholders  

## Deliverables
- Power BI dashboards (KPIs, country sales, forecasts)  
- Interactive visuals and mobile views  
- Final **PBIX file** with professional formatting
